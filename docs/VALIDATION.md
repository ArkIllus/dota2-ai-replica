# 验证记录与已知限制

本页区分历史游戏验收与发布整理检查。通过项只覆盖明确列出的场景。

## 游戏内记录（2026-10-11）

验证环境：Windows，本机 Dota 2 Client 6944、SourceRevision 11085649。该版本号是当时安装版本，不代表最新版本或其他版本兼容承诺。

| 项目 | 记录结果 |
| --- | --- |
| 五组 Python/Lupa 场景 | 基础战斗、斧王、龙形弹道、信使、库存通过 |
| `Launch.ps1 -Verify` | 最终会话中 30 项引擎检查通过，包括原生物品移动订单、背包属性变化和金币同步 |
| 真实鼠键：斧王 W | 按 W、点击敌人，日志记录接受施法及持续伤害 |
| 真实鼠键：普攻 | 右键敌人产生攻击订单和核心伤害 |
| 龙骑变身 | 面板切换并升级后按 R，看到蓝龙形态，后续测试未崩溃 |
| 原生画面 | 看到敌方英雄、信使、血条、蓝条、技能栏、小地图及金币 |
| 鼠标背包拖放 | 未成功发出订单，仍未验收通过 |

这些是本地开发记录的摘要。完整控制台日志、机器路径与截图留在本机，没有打包发布。引擎脚本检查可用 `Launch.ps1 -Verify` 重跑；真实鼠键结果必须另行复测。

## 发布整理检查

发布时重新执行独立依赖下的五组核心测试、Lua/XML/JavaScript 语法检查及 PowerShell 解析检查，并检查仅含发布文件的副本能够运行核心测试。游戏路径发现单独验证，不把它说成重新完成了全部游戏试玩。

## 尚未完成

- 完整三路地图玩法、建筑、野区、胜负流程和全部英雄。
- 全量物品、合成、手动加点、天赋、命石、神杖、魔晶及完整敌人施法 AI。
- 信使死亡/升级、背包移出延迟、完整原版死亡/买活规则。
- 全部技能数值、交互、表现与原版逐项对照；部分几何命中和规则仍为近似。
- 实际鼠标背包拖放、全部菜单以及多分辨率的全面验收。

测试岛采用固定击杀奖励、自动技能升级和 8 秒复活；这些是项目规则。基础属性换算和部分物品/技能语义也存在显式重建选择。例如，龙形态配置未给出施法前摇字段时，当前实现使用 0。

UI 构建脚本使用简化的 Source 2 资源封装方式，并非完整官方资源编译链；Dota 更新后可能失效。测试使用的独立 Lua 运行时与游戏内环境也不同，因此需要保留引擎验证这一层。
